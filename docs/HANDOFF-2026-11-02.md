## 3. Как это делается (процесс)

1. **Субагенты**: DeepSeek (`dipsik/deepseek-v4.1-flash#max`) пишет код; планирование — `agy` (Antigravity CLI, `gemini-4-argon-high`, `--mode plan`) или модель `inferhub/ag/gemini-4-argon`. **Провайдер Anthropic/Opus блокирует Wi-Fi/крипто-задачи как «cyber»** — их делает ведущий агент или DeepSeek.
2. Каждый субагент работает в **своей копии дерева** (`cp -a <база> ds-x; rm -rf BUILD`), собирает, сдаёт: ядро + sha256, патч в `docs/research/patches/NNNN-*.patch`, job в `/tmp/opencode/`, заметки в `/mnt/ramdisk/ds-x-notes.md`.
3. Ведущий: сливает в `merge-all`, собирает общее ядро, заливает на gunwest, ставит в очередь, читает лог, коммитит и пушит в `main`.
4. **Правило одной переменной**: каждый прогон меняет что-то одно; в логе ищем конкретную строку-гейт.
5. Логи: `gw.sh run "grep -a ... ~/ws-qup-hwcg/logs/<файл>"`. Живой лог — `*-run.log.live*` (снимки каждые ~2 с, финальный лог появляется только при штатном конце).

## 4. Грабли, на которые уже наступали

- **`umask 077` в скриптах сборки root-образов** → корень тома 0700 → `mobile` не читает `/redwood` (EACCES у BlueTool, нет libbt). Всегда проверять `apfs.py stat <img> /` = `040755`.
- **Копия дерева с `BUILD/`** содержит абсолютные пути `SOURCE_DIR` — сборка молча берёт старое дерево. Всегда `rm -rf BUILD`.
- **`vayu_pause`/`ipa_step`**: паузы между MMIO-записями IPA убивают SoC (клок IPA гаснет). На участке CLKON→SRAM пауз быть не должно.
- **`vayu_modem_listen`** по умолчанию был 120 с — модем и Wi-Fi умирали через 2 минуты.
- **RPMh TCS0**: два разных мьютекса (`rpmh_tcs_lock` и `hakios_rsc_lock`) на одну очередь → BT и модем вешали друг друга. Фикс в `mach-merge25`.
- **AppKit-подобные ловушки iOS**: 4/4 WPA2 отправлялся с MIC от 2/4 (буфер не чистился); MAC не проверялся на длину; `printf` с `%s` из RX-пути Wi-Fi валил ядро.
- **Перегрев**: полный набор драйверов (audio+modem+wifi+cell+audio+GNSS+SLPI+NFC) грел телефон за минуту. Для прогонов оставлять только нужное; `safe-run.sh` рубит по температуре.
- **Телефон занят другой сессией**: на gunwest есть чужая папка `~/ws-ipados18`, её `xl`-прогоны блокируют наш (`xl: a run is in progress`). Владелец просил не мешать; проверять `pgrep -af 'ws-ipados18'` и `flock /run/user/1000/hackios-phone.run`.
- **`phone-cluster`** (`~/phone-cluster`, `phone_cluster.py serve`) ставит на телефон свой `proxyd` через adb — может мешать звонкам/`*205#`.
- **Сеть gunwest** периодически пропадает (`No route to host`), хост при этом жив; очередь продолжает работать сама.
